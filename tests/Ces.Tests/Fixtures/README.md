Test fixtures (4 s, 440 Hz sine + noise, generated by ffmpeg `sine`/`anoisesrc`):

- src.wav — the 16-bit 44.1 kHz source
- lame3100-v2.mp3 — LAME 3.100 (stock Debian build) `-V 2`
- lame3100-cbr128-crc.mp3 — LAME 3.100 (stock Debian build) `-b 128 -p` (CRC protected)
- ffmpeg-cbr192.mp3 — ffmpeg libmp3lame 192k
- ffmpeg-l5.flac / ffmpeg-l12.flac — ffmpeg FLAC encoder, compression level 5 / 12
- ffmpeg-24bit.flac — ffmpeg FLAC, 24-bit 96 kHz
- udf102.iso / udf250.iso — UDF 1.02 and UDF 2.50 (metadata partition) images made with Windows IMAPI2
  (readme.txt, VIDEO_TS/VTS_01_1.VOB = lame3100-v2.mp3, BDMV/STREAM/00001.m2ts = ffmpeg-l5.flac)
- rar/set4.* — RAR 4 stored, old-style volumes (.rar .r00 .r01 .r02): lame3100-v2.mp3 + udf102.iso
- rar/set5.part*.rar — RAR 5 stored, 5 volumes: ffmpeg-l5.flac + udf250.iso
- rar/packed.rar — RAR 5 compressed (-m3): lame3100-v2.mp3

- ffmpeg-mono22k.mp3 — ffmpeg libmp3lame 64k MPEG-2 mono (LAME tag CRC over 190 bytes, FFmpeg style)
